# M3 Solutions Invoice Builder (Background Version)

This version uses the supplied invoice PNG as the full background image.

## What is editable
- Invoice number
- Invoice date
- Customer name
- Customer phone
- Customer website/email
- Item list
- Item amounts
- Tax
- Currency

## Notes
- The background image already contains the design, logo, terms, and payment section.
- The HTML adds only the changing invoice details on top of that image.
- Open `index.html` in any modern browser (Chrome, Edge, Firefox, etc.).
- Click **Print / Save PDF (Download)** to instantly download an Ultra HD 300 DPI A4 PDF file matching your preview.
- Use **Print** to send directly to your physical printer using the browser print dialog.
